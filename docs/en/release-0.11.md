# 0.11 · Revolution

[中文](../release-0.11.md) · English

Version 0.11 introduces the Graphite/OneGUI visual system, minimal/practical/full experience modes, a language-first onboarding flow and a shared search/OH/plugin introduction in all modes.

Full mode adds the free whiteboard workspace, tabs and OneGO, staging and online sharing codes, organizations, plugins and Xiaoda/skill-plaza integration. The guide records a real long-press drag with fictional content. The staging button remains freely movable and uses a subtle target scan during a drag rather than an obstructive inventory radar.

OneShot defaults to Study, Reservations, Life, Information and Schedule. Available assignment deadlines belong in compact-mode schedules too. Mode switching preserves hidden full-mode data.

Lightweight skills use a bounded pure-JavaScript QuickJS runtime. Heavy environments require export to an external desktop agent. Native networking, second-factor continuity, cloud ownership and conflict handling have their own verification boundaries. NFC remains unreliable; prefer short codes.

The public README and website show fictional portrait, landscape and desktop captures. This document describes the source version; [Releases](https://github.com/smartThise/OneTHU/releases/latest) is authoritative for actual available packages. It does not announce a new APK or Windows build by itself.
