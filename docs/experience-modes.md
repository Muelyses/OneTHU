# 三种使用模式

中文 · [English](en/experience-modes.md)

三种模式使用同一个应用与基础数据层。切换模式调整功能可见性，不删除完整模式的存档。完整模式内容在极简、实用模式隐藏，接收与自动导入也有相应隔离。

| 能力 | 极简 | 实用 | 完整 |
|---|---|---|---|
| 首页 | 今日待办、即将上课 | 今日内容、常用入口与更多功能 | 自由白板与组件 |
| 底部入口 | 学习、预约、生活、信息、课表 | 常用入口与功能目录 | OneShot 可配置 |
| 搜索 | 当前模式支持的功能与内容 | 当前模式支持的功能与内容 | 页面、服务、收藏与校园对象 |
| OH | 对话、自填 API、微信/飞书接入 | 对话、自填 API、微信/飞书接入 | 模型、工具、插件联动及轻量技能 |
| 标签页、工作区、OneGO! | 隐藏 | 隐藏 | 可用 |
| 暂存箱、名片、组织、分享接收 | 隐藏并隔离相关接收 | 隐藏并隔离相关接收 | 可用 |
| 插件与主题扩展管理 | 介绍完整模式的扩展能力 | 介绍完整模式的扩展能力 | 安装、启停和管理 |
| 完整布局与资料存档 | 保留 | 保留 | 恢复原有内容 |

极简模式用于直接进入日常任务；实用模式保留完整的基础服务目录；完整模式提供可组合的工作环境。设置中的「使用模式」负责切换，导览中的模式体验也走同一状态。

## 搜索与 OH

三种模式均保留胶囊。搜索结果受模式限制，不通过搜索绕过隐藏功能。OH 与搜索是同一入口内的不同工作方式；搜索用于定位，OH 用于对话与受当前模式允许的工具能力。插件管理在完整模式开放，精简导览提供模式切换入口。

## 模式切换与同步

完整模式的白板、名片、好友和组织索引不会因进入精简模式而清空。进行中的异步同步、分享接收与技能调用会检查账号和模式修订号；旧请求不能在新模式落入隐藏内容。名片与组织索引同步详见 [分享与组织](sharing-and-organizations.md)。
