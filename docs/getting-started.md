# 安装与开始使用（0.11）

中文 · [English](en/getting-started.md)

## 安装与升级

发布附件来自 [GitHub Releases](https://github.com/smartThise/OneTHU/releases/latest)，官网的下载入口指向同一发布页；清华云盘镜像见 [官网下载页](https://onethu.github.io/download.html)。版本以实际附件与应用「我的 → 关于」为准。

| 平台 | 安装与基础环境 |
|---|---|
| macOS | 按芯片选择 DMG；开发时使用 Xcode 命令行工具 |
| Windows | 使用 EXE 安装器；需要可用的 WebView2 运行时 |
| Android | 使用当前发布的 APK；允许该来源安装，通知与相册等权限按实际功能申请 |

正式版与开发者版使用不同应用标识，开发者版不会自动替代正式版。相同版本号也可能来自不同提交，故障反馈同时附构建信息。签名不同的 Android 包可能无法覆盖安装；卸载会删除本机数据，升级前应确认包来源与备份范围。

## 登录与设备身份

使用清华统一认证账号，按学校要求完成微信、短信或动态口令验证。应用保留同一设备指纹；保存登录状态与资料同步不是同一件事。邮箱、雨课堂、云盘、GitLab、清小搭等服务可能需要单独接入或出票，统一认证不能保证所有服务始终免验证。

反复点击登录不会加速认证。新的主登录链有 20 秒冷却，刷新仍保留本轮计时；继续验证码验证不受该冷却阻断。学校限流、信任设备上限或页面改版会给出不同说明。排障路径见 [隐私与故障处理](privacy-and-troubleshooting.md)。

## 选择语言和模式

首启第 0 步用中英文询问语言，选择后后续导览使用已安装的该语言词典。设置里可切换语言并重播导览。0.11 提供极简、实用、完整三种模式，切换只调整可见界面，保留完整模式的布局、名片与其他本机设置；详见 [使用模式](experience-modes.md)。

所有模式都会介绍搜索、OneTHU Harness（OH）及插件的适用范围。完整模式再介绍白板、暂存箱、短口令、NFC、组织与清小搭。导览能跳过、返回和重播；体验按钮打开真实功能，继续导览回到当前课。

## 日常入口

- 搜索胶囊：查找当前模式可访问的功能与内容；切到 OH 进入对话。
- OneShot：底部清晰的学习、预约、生活、信息、课表入口；可配置范围随模式变化。
- 首页：极简模式显示今日待办与即将上的课；实用模式增加常用目录；完整模式使用可编辑白板。
- 我的：管理当前模式的设置；完整模式另含个人名片、插件等管理入口。
- 强制刷新：拖动可换位置，短按执行刷新；页面自身刷新用于重新取当前模块数据。强制刷新不会自动清除学校信任设备。

## 接入与提醒

雨课堂在外部作业源设置中扫码或网页登录；邮箱与日历使用相应协议账号或授权码；云盘与 GitLab 按界面完成认证。接入与使用说明见 [作业](homework.md)、[日程与同步](schedule-and-sync.md)、[分享与组织](sharing-and-organizations.md)。

通知需要操作系统授权。后台限制、精确闹钟权限和厂商省电规则会影响 Android 提醒；系统小组件与应用内白板组件属于不同功能。应用内浏览器预览不能替代原生通知、NFC 或下载权限验收。
