# OneTHU 术语与动作约定

以下为本轮英文默认口径。简体中文是产品事实源；其他语言按含义翻译，品牌保留。

| 中文 | 英文 | 说明 |
| --- | --- | --- |
| 首页 | Home | 不叫 My Whiteboard |
| 白板 | Board | 用户可自由摆放组件的画布 |
| 组件 | Widget | 首页/白板可添加的元素 |
| 工作区 | Workspace | 一组标签页 |
| 标签页 | Tab | 包含首页标签 |
| 我的 | Me | 用户设置入口 |
| 我的名片 | My card | 个人资料卡 |
| 通讯录 | Contacts | 好友与组织入口 |
| 暂存箱 | Stash | 全站统一；不要与云盘 Trash 混淆 |
| 口令 | Share code | 分享读取口令，不是账号密码 |
| 短口令 | Short share code | 联网取回内容的短码 |
| 碰一碰 | Tap to share | NFC/近距离分享 |
| 一级功能区 | Main features | 首页功能入口 |
| OneShot | OneShot | 保留品牌，不自行改成 Dock |
| 极简模式 | Minimal mode | 极简固定首页 |
| 实用模式 | Practical mode | 精简日常使用 |
| 完整模式 | Full mode | 白板、工作区等全部功能 |
| 网络学堂 | Web Learning | 学校服务名，和 Learn 课程学习动词区分 |
| 雨课堂 | Rain Classroom | 独立作业源 |
| 日程 | Schedule | 课程、作业截止及个人安排 |
| 课表 | Timetable | 课程时间表 |
| 待办 | Tasks | 用户待办，和作业 Assignments 区分 |
| 作业 | Assignment | 学校作业，不译为 Task |
| 截止时间 | Due date / Deadline | 截止状态用 Due / Overdue |
| 清华云盘 | Tsinghua Cloud Drive | 存储服务 |
| 组织 | Organization | 真实成员、角色与资源权限 |
| 负责人 | Owner | 不与 Admin / Member 混用 |
| 石墨 | Graphite | 默认主题 |

| 动作或状态 | 英文 | 必须保留的区别 |
| --- | --- | --- |
| 生成口令 | Create share code | 创建新的分享 |
| 复制口令 | Copy share code | 复制已有值，不创建 |
| 接收 / 导入 | Receive / Import | 将分享内容加入本地 |
| 存入暂存箱 | Add to Stash | 保留可引用对象 |
| 取用 | Open / Use | 依据场景，不意味着删除 |
| 删除记录 | Delete record | 仅清本地记录 |
| 撤销分享 | Revoke share | 让远端分享失效，可能需要网络 |
| 已保存 | Saved | 不保证远端同步 |
| 已同步 | Synced | 服务端确认成功 |
| 待同步 / 待重试 | Pending sync / Retry needed | 不得译成成功 |
| 无权限 | Access denied | 不得改成资源不存在 |
| 尚未确认 | Not confirmed | 不得改成成功或失败已确定 |
| 断开连接 | Disconnect | 不代表删除远端内容 |
| 退出登录 | Sign out | 本机账号会话退出 |
| 前往 | Open | 打开对应课程/作业标签页 |
| 寻迹 | Directions | 前往课程地点的导航 |
| 整包更新 | App update | 下载并由系统安装，不叫 live update |

专有名词或真实机构没有官方译名时保留原文。不要为了“全英文”编造清华院系、课程或老师姓名的英文。
