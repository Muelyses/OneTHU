# 工作台五项反馈修复

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../../README.md)；英文入口见 [English overview](../../en/index.md)。


2026-10-17，继续在 `exp` 修复用户逐项指出的问题。

1. **竖直标签页收起时被裁半边**：窄轨仍是 56px，但新工作台给了左右各 12px 内边距，44px 图标槽装不下。改为 4px 水平边距并让主按钮占满剩余宽度；图标在悬停展开前后位置不变。
2. **左上角名称**：入口文案改为“标签页”，与点击后打开的功能一致；角标保留标签数量。
3. **二级 Segment 辨识度**：OneGUI Segment 与存量 SegmentedOverflow 共用轨道、边框、选中底色和文字角色。轨道有明确灰阶与边界，选中项使用黑白高对比动作色对；浅色、深色主题分别解析。四种便笺纸色及选中态加入真实令牌对比度检查。
4. **研讨间重复选时**：点房间时段后立即弹出标准确认窗，携带该段起止时间；使用空闲时段筛选时带入完整筛选范围。确认窗不再重复全天表，只提供开始/结束微调；最短/最长时长、占用与过期约束仍校验。提交按钮在固定页脚，成功有即时提示，错误和首次邮箱绑定重试留在确认窗中。修复了时间下拉 portal 原层级低于 OneGUI Modal、导致无法点选的问题。原先多人房间前端一律禁用提交，与既有“由馆方校验本人提交”的逻辑矛盾，本轮取消这项静默阻断，仍展示人数要求并保留馆方拒绝信息。
5. **便笺黄色与保存**：保存曾写入 `BoardItem.props`，渲染投影却丢掉它并只读 `spec.props`。现在自定义组件更新写入规范的 `spec.props`，同时兼容旧外层字段；因此旧版本确实已经写入本地的内容也能显示。输入即保存，刷新时无需先失焦。便笺整张卡使用不透明纸色，默认纸黄，深色主题也使用深色墨迹；纸色集中到 Reference/Semantic，不再使用组件内字面颜色。
