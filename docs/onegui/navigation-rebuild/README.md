# 导航、传输与暂存箱 · 收尾记录（2026-10-18）

接手 codex 的半成品（先整笔留档 `5ef7618b`），按用户 8 条验收清单收尾。本目录是导航/传输/暂存箱这部分的证据与截图；通讯录与日程分别见 `contacts-*.png` / `schedule-*.png`。

## 这一轮改了什么

1. **暂存箱半圆雷达重做**。旧版是一个空的大白碗（`before-radar-ugly.png`）：没有刻度、没有光束、条目在圈里旋转导致文字歪斜，空箱时只剩两个按钮飘着。现在是半圆刻度环：环带 + 刻度 + 两道扫描光束，箱内条目沿弧环绕缓慢摆动且文字始终正向，中心显示件数与箱子名；空箱给一句「长按任意内容，拖进来」。
2. **完全展开改成下弹抽屉**（用户口径：不要跳新页面）。抽屉里有清单、逐项移除、打开、以及「在标签页打开」；手机与桌面同一套。雷达页脚「打开展示柜」与条目都指向抽屉。
3. **拖动/投递修好了**。此前长按后拖动会被浏览器原生 HTML5 拖拽打断（pointercancel），松手放不进箱子；现在拾取后立即拦截 `dragstart`，拖到箱子即入库，拖到 OH 胶囊即发给小OH，取消不写入。
4. **手机顶栏**去掉 OneTHU 字样，暂存箱按钮绝对居中（首页在左、我的在右）。
5. **OneGO 收藏栏**位于 OH 胶囊下一栏，黑色 OneGO! 入口 + OnePage/工作区书签 + 放不下时的填充小三角溢出菜单。
6. **OneShot 四枚独立胶囊**（网络学堂/日程/待办/生活）：补注册了「待办」「生活」两个一级入口，不再出现「入口已删除」；配置挪到「外观」；手机刷新/回顶按钮上移，白板工具竖排在右，画布底部留出空间。
7. **暂存箱页**操作分「收进来 / 发出去」两行，修掉按钮挤压重叠。
8. **名片云盘邮箱自动识别**：`resolveCloudEmail()`（名片 → 云盘账号 → 校园 info 邮箱 → CalDAV），不再让用户手填，也不提「登录」。
