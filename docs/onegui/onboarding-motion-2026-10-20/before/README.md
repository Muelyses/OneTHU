实看问题：

- 320×568 模式选择首屏只露出极简卡；其他两种模式需要内部滚动发现，无法直接比较。
- 844×390 进入完整第一课时正文保留了滚动位置，标题和进度已在上方，截图从图示开始。用户难以判断自己正在看哪课。

- 完整 11 课串成一条主线，核心白板/暂存箱/口令/NFC/组织与其他功能同权，无法先完成核心后按需探索。
- 采样的各模式第一课舞台都是静态 `span/div`：12 个样本均无按钮和活跃动画，见 [report.json](report.json)。

这批基线只覆盖各模式第一课和开场，不宣称其他旧课全无动画（例如旧 NFC 有独立脉冲）。浏览器关闭自然完成，日志 `/tmp/onethu-onboarding-before.log`。
