## 模型映射

机身高 2.6 个场景单位，等同 150 mm，因此 1 mm ≈ 0.01733 单位。宽、厚与屏幕尺寸按同一比例换算。

| 元素 | 取值（场景单位） | 说明 |
| --- | --- | --- |
| 机身轮廓 | 1.2463 × 2.6 × 0.1517，圆角 0.21 | `createPhoneSlab` 以五次曲线构造 G2 连续轮廓，XY 圆角与厚度无关 |
| 前盖玻璃 | 面积随截图，外边距 0.0115，圆角 0.17 | 边框金属由机身倒角呈现，不额外绘制色带 |

材质沿用运行时解析的 OneGUI 令牌：`--og-studio-edge` 用于铝金属，`--og-studio-body` 用于超瓷晶背面，`--og-studio-glass` 用于屏幕玻璃，`--og-media-ink-dark` 用于前盖与深色件。浅色与深色主题各自取值。

## 保持不变的行为

- 真实应用截图直接作为纹理，不重绘、不拉伸；UV 覆盖整张图，按 contain 取最大尺寸。
- 截图圆角由几何遮罩实现，与物理屏幕圆角一致；四角像素不参与渲染。
- 前摄不覆盖截图控件，节点名保持 `<设备名>-front-camera`，供既有测试查询。
- 所有几何、材质、纹理登记在装配体资源集合，`dispose()` 各释放一次；视频分支保留首帧/末帧与暂停语义。
- 姿态编排未改动，NFC 双机、白板、卡片场景沿用原有 `applyPose`。

## 回归入口

```bash
# 机模几何 + 真实 Vite 模块集成（145 项）
ONETHU_BASE_URL=http://127.0.0.1:5180 \

node tools/onboarding-phone-model-test.mjs

# 导览视口：8 种窗口尺寸 × 15 个阶段，含机模投影检查
ONETHU_PLAYWRIGHT_PATH=/path/to/playwright/index.mjs \
node tools/onboarding-viewport-browser-test.mjs
```

`ONETHU_PHONE_MODEL_UNIT_ONLY=1` 只运行纯几何断言，报告中明确标注浏览器集成已跳过。`ONETHU_TEST_URL` 指向已有的 Vite 服务；测试不启动替代服务。

## 已知限制

- 姿态由课程编排决定，静止画面以正面为主；背面细节在 NFC 片段的旋转过程中可见。
- 天线注塑条、法规文字与 Apple 标志未建模，避免在真实截图上叠加臆造界面。
- 相机平台、按键与闪光灯的相对位置属于视觉近似；官方仅公开镜头位于左上角这一事实。
- 浏览器端检查覆盖 Chromium；Tauri WebView2 的原生渲染未在本工作区实测。
