# OneGUI Workbench · 第二轮验收

2026-10-17，`exp` 基于首轮 `c1035198` 继续。用户指出首轮几乎看不出变化，本轮的验收对象改为真实页面结构、完整视觉层级与可用交互。

## 整页变化

- 首页：工作台页头与右侧时间、整行服务导航、白板工具栏，按文档流组织；自由画布和笔迹仍使用原数据。已有摆位不自动重排。
- 新安装：默认白板为可读的三列卡片，不再将全部组件挤成一列 90/286 像素窄卡。旧布局迁移保留原通道；纯模型测试覆盖两者。
- 导航：统一命令栏、活动标签、OneGO 主要动作；横/竖标签模式与手机上下导航仍可使用。
- 设置：桌面中央窗口、左栏目右内容；手机全屏、单行横滑栏目。移除重复的一级导航；方向键和 Home/End 能切换栏目。
- 服务管理与功能目录：使用真正的 OneGUI Modal；标题、关闭、焦点、Escape 和退场统一。保留用户服务顺序、增删、插件目录和透明度设置。
- 组件：新的标题/显示字号、控件密度、卡片曲率和面差；可点击 Chip 使用原生按钮，可删除 Chip 使用两个同级按钮，避免嵌套。

## 令牌与样式归属

`gui.css` 管 Reference → Structure → Semantic → Material → Components。
`onethu.css` 只负责导入 `compatibility.css` 和 `workbench.css`：前者为存量别名与适配，后者为当前产品排版。颜色字面值只在 Reference；产品几何只在 Structure，组件只引用角色。

| 语义 | 当前规则 |
|---|---|
| 环境 / 内容 / 输入 / 浮层 | canvas / paper / well / overlay 四层 |
| 页面标题 / 标题 / 正文 | 36 / 24 / 14；工作台主标题 44，手机 28 |
| 主要控件 | compact 36、comfortable 40、touch 44 |
| 内容曲率 | card 24、control 14、menu 14；胶囊用于标签 |
| 桌面页头与导航 | 命令栏 60、标签栏 44；手机顶部 52 |
| 主要动作 / 用户主题 | action 黑白对独立于 accent，仍支持原主题和玻璃档位 |

本轮删除 68 条过期宿主声明和相应空规则/过时注释；旧 CSS 从 9959 降至 9811 行，应用裸控件从 257 降至 245。存量页面迁移尚未归零，不能把本轮核心界面重构称为全仓旧控件全部消失。

## 验证

- desktop typecheck、production build；构建仍有既有大包与混合导入提示。
- OneGUI 九项规则 + 28 组真实令牌对比度、scope 继承、主题往返；令牌/CSS解析/对比度护栏。
- Board model、旧键迁移 13 场景、重叠不变量；新增默认三列/旧布局保护检查。
- `visual-report.json`：11 个亮/暗、桌面/手机、设置/搜索/菜单/画廊场景，运行异常与文档横向溢出均为零。
- `interaction-report.json`：真实鼠标拖动 60×40、持久化重载、键盘开启服务弹窗、入口增删、Escape、设置栏目、搜索直达、手机末尾栏目可达。
- `additional-report.json`：竖标签栏及键盘 Home/End 栏目操作。
- 手机首页与设置 390×844@3：横溢出、文字截断、文字互压均为零；存量天气的“刚刚”按钮仍是小触目标。
- 像素审计：首页亮色和搜索暗色无低于 AA 文本。设置审计在滚动视口底边有一处取样误判：被面板下沿裁切的长说明背景采到了面板外的遮罩；截图人工复核，文本实际在白色卡片上（见 `settings-contrast.png`）。
- 总 `pnpm guard` 在 8 处既有文案违规停止；没有据此宣称整条总链通过。

真实校园服务登录后的全量页面、原生移动端与语音性能未在本轮重新验证。截图使用预览环境，课程/作业空态和骨架是实际未连接状态，不是虚构数据。
