# OneGUI exp Implementation Plan

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../README.md)；英文入口见 [English overview](../en/index.md)。


**Goal:** 在本地 dev3 的 exp 分支建立 ChatGPT / Codex 方向的完整中性视觉语言，保留 OneTHU 的基础设计思维与 UX。

**Architecture:** Reference → Semantic → Structure → Material → Components → OneTHU recipe。OneGUI 是视觉值的唯一来源；宿主保留路由、数据和布局。现有设置仍驱动明暗、主题色、密度和材质，强调色与主要动作分离。

**Tech Stack:** React 19 / TypeScript / CSS custom properties / Vite / Playwright。

## 视觉定案

采用中性工作台路线：白与炭灰面阶、可见而克制的边界、黑白主要动作、低饱和业务色、圆润输入区与精确字阶。另两种路线（完整复制 ChatGPT 的会话布局、继续增强玻璃质感）不采用：前者改变现有 UX，后者延续多套材质竞争。保留首页自由画布、程序坞、标签页/工作空间、OH、OneGO、设置抽屉及手机导航。

## 实施

1. 读取近期记忆与现有令牌/管线/组件；创建 exp（基线 90eec5b2）。
2. 重整中性参考阶、明暗语义、动作/输入/壳层角色、密度、圆角、排版、阴影和动效。
3. 重做材质：玻璃保持可选，四档由统一 opacity 公式推导；控件与浮层保持可读。
4. 按钮、卡片、输入、分段器、菜单与焦点共用角色；主要动作与主题 accent 正交。
5. 将兼容别名与应用外观配方收进库；应用旧文件保留布局，删除被接管的外观规则，不叠第二套主题。
6. 修复主题回到默认时 accent 未清空的问题；保留用户存储。
7. 运行 typecheck/build、OneGUI/令牌/CSS/对比度护栏；浏览器验证桌面和手机、明暗、玻璃及设置/搜索/菜单。
8. 保存截图和验收报告，记录历史遗留与未覆盖的真机行为；写回 MCP。

## 验收标准

- 同类控件共用同一角色；组件 CSS 无字面色和独立尺寸。
- 默认主要按钮在明暗两档均达到 4.5:1；次要文本保持可读；键盘焦点可见。
- 手机没有新增横向溢出、遮挡、标签条复活；桌面工作空间和白板坐标保持原契约。
- 不把旧样式全量迁移归零或预览页通过等同于所有登录后页面/真机已验收。
