# OneGUI Workbench — 第二轮视觉重构

用户反馈：第一轮变化几乎不可见。验收改为真实首页、设置和搜索整页截图，不能用令牌变更数量代替视觉结果。

## 设计决策
- 石墨/暖纸工作台：环境底、内容面、输入井、浮层四层明确；主要动作使用实心墨色。
- 首页从覆盖式钟/程序坞转为文档流：工作台标题与时间 → 服务导航 → 自由画布。自由画布数据、拖拽、缩放、笔迹和工作区保持。
- 大字阶与稳定阅读宽度，服务入口改为排版清楚的图标导航；移除玻璃时代的圆球、扫光、悬浮弹跳和重复边框。
- 设置桌面使用左侧栏目 + 右侧内容，手机仍保持可横滑栏目。栏目语义和检索直达保持。
- OH 搜索以清楚的标题、输入、结果列表组织；弹层、菜单和表单复用 OneGUI 同一组角色。
- 样式变更归库，过期宿主样式删除，禁用新增硬编码外观；现有用户摆位不自动重排。

## 实施与验证
1. 重新定义结构/表面角色，统一库组件密度和标题层级。
2. 首页结构、服务入口、画布工具栏，默认新板合理尺寸。
3. 设置双栏结构、OH、导航和浮层配方；清理竞争样式。
4. 实际浏览器检查亮暗/手机/纵横标签/设置栏目/搜索/画布拖动与存储不变。
5. typecheck、build、OneGUI guards、CSS解析；截图提交并记录边界。
