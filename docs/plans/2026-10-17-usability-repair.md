# 首页 / 白板 / 玻璃 / OH 可用性修复

用户反馈：标题错误、100% 画布超屏、滚轮被吞、移动与缩放被锁住、设置冗余说明、玻璃失去原有透光质感、OH 专属按钮泄漏到搜索/清小搭、胶囊按压回弹丢失。

- 首页标题统一为首页。
- 100% 为适合当前页面宽度的基准视图。基准比例与用户缩放分离，所有拖动/拉伸/落点/画笔相关坐标使用真实显示倍率。文档存储坐标不变，基准不会在拖动过程中跳动。
- 首页滑动待办的普通滚轮交还页面；卡片触摸/拖动与独立待办页的轮播保持原有行为。
- 桌面恢复非交互卡体的直接移动和点选缩放。手机浏览仍按阅读顺序排布，点卡片选中后用浮条上移/下移/增高/减高。
- 玻璃复用历史透光档、模糊、饱和度和高光边；配色与材质继续分离。保留文本/图标自动对比度引擎，修正现代 CSS 颜色解析和状态按钮误锁色。
- 创造/新建/历史/导入导出/朗读只在 OH 模式出现；收起常驻。胶囊恢复指针/键盘按压回弹，输入框/语音手势不误触。
- 用真实滚轮、无需进入编辑的鼠标操作、触屏指针、旧布局、多个窗口宽度、真实壁纸与文本引擎探针进行验证；检查截图而不只检查 blur 属性是否存在。

## 接手后的追加（2026-10-17 晚，本分支）

- 选中失焦：点画布空白（含世界层）、页面其它区域、组件里的按钮/输入都退出选中；浮条与把手自己不清。
- 壁纸下首页标题板跟随玻璃材质（`--og-fill-surface` + `--og-surface-blur`），不再是一块不透明白板。
- 移除“编辑布局”模式：删除拖拽把手、编辑布局/完成按钮、相关提示文案与 `is-layout-editing` 样式；桌面直接拖动，手机堆叠点选 + 浮条调整。
- 空白右键与「＋」统一为同一个组件选择器（BoardAddDrawer）：缩略图网格 + 搜索框 + 文件夹/OnePage 特殊项；右键记住落点。
- 顺手修复根目录 `pnpm build`（packages/gui build 脚本未加引号导致 sh 语法错误，dev3 同样存在）。
