# 联网短口令

用户明确选择：默认全部联网，不再生成供用户分享的离线长串。旧口令继续接受。

## 方案

复用清华云盘已有的分享凭据。20 位十六进制 token 无损转为 16 位易读 Base32，四位分组，加 ON 前缀，共 22 字符。名片、箱子和组织内容都上传为 manifest；口令长度与内容大小无关。非标准 token 保留完整凭据，不能截断减少随机性。不引入短码服务器或公共映射表。

所有新分享都需要发送方连接云盘；接收方联网匿名读取分享，不必先连接自己的云盘。云盘控制七天有效期与撤销。短码只包含分享凭据，不含登录 token、仓库 ID、私有目录或头像。旧 ONV1/ONV2/ONTOUCH1/ONORG1 继续可导入。

## 实施与验证

- [ ] 共享短码编码、识别、解析与云清单发布。
- [ ] 暂存箱 / 个人名片 / 组织邀请 / 组合分享全部使用短码，NFC 与二维码一致。
- [ ] 所有接收入口识别新旧口令，接收内容保存逻辑保留。
- [ ] 测试长度、无损转换、大小写/分隔符、旧协议兼容、无云盘/过期/损坏失败，以及跨独立客户端读取。
- [ ] 类型检查、浏览器界面与自动化验收，更新记忆。

不部署或使用自建服务；云盘真实互传另行真机联调。
