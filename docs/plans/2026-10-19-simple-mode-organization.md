# 极简模式、组织管理与收发整理 Implementation Plan

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../README.md)；英文入口见 [English overview](../en/index.md)。


**Goal:** 修复固定首页标签叠字，统一暂存箱收发入口，补全组织工作区，新增不破坏完整模式存档的极简体验和开屏导览。

**Architecture:** 极简模式使用独立偏好键与临时导航，完整模式标签/白板/OneShot存档不被改写；共同内容页、OH胶囊和原生接入流程复用。组织记录是唯一真源，名片从组织派生；文件走已有清华云盘，成员/项目/公告保存于组织记录。

**Tech Stack:** React/TypeScript、OneGUI语义与结构令牌、现有Tauri/清华云盘桥、Playwright真实组件验收。

起点：exp / 945824c0（dsh 短口令收尾，已完成，不重做）。

## Task 1 固定首页标签
- [ ] `packages/gui/src/recipes/workbench.css` 给sticky首页稳定不透明底层，保持选中态与玻璃栏；测试标签横向滚动不透字。

## Task 2 独立模式和五入口
- [ ] 新增 `state/experienceMode.ts`：full/simple 偏好、独立导航和模式事件；不写 explorer/board 存档。
- [ ] `quickAccess.ts` 新默认学习/预约/生活/信息/课表，保留旧自定义配置原值；simple固定五入口。
- [ ] `Layout.tsx` / `TabHost.tsx` / `BottomBar.tsx`：simple只挂简洁壳、固定首页与当前内容，不露标签/OneGO/白板/暂存箱/名片；完整原路保留。
- [ ] 真实浏览器切换前后对比完整模式存储、标签和布局。

## Task 3 极简首页、设置与导览
- [ ] 简洁首页只有今日待办与即将上课，复用课程/待办数据组件。
- [ ] 精简设置：模式切换、必要账号、外观基础、OH自填API、微信/飞书基础扫码；完整设置也提供模式切换。
- [ ] 新导览：选择模式→功能说明→可跳过雨课堂/IM接入；不重置已有数据，不自动发送消息。
- [ ] OH/搜索保留，simple隐藏创造模式及高级工作台入口。

## Task 4 暂存箱收发
- [ ] 抽共享操作组件，雷达/抽屉/标签页都具备分享口令和统一接收，不再重复「导入口令/收碰一碰」等同义动作。
- [ ] 标签页保留箱子管理/条目管理；组合分享独立为可选项，不占主流程。
- [ ] 用假云盘验证每处生成/复制/接收/NFC反馈。

## Task 5 组织工作区
- [ ] `state/org.ts` 扩展可持久化项目/公告、成员角色/删除保护、组织名片派生。
- [ ] `OrganizationSection.tsx` 组织详情统一成员/文件/项目/公告；文件使用真实云盘列举/上传/删除。
- [ ] `NameCardSection.tsx` 停止单独创建组织名片；旧名片数据保留可读，组织创建后自动关联展示。
- [ ] 验证CRUD保存、重载、组织隔离、名片同步、旧数据兼容；真实跨账号同步边界明确记录。
