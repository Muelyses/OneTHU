# 导览落点与模式边界验收（2026-10-20）

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../README.md)；英文入口见 [English overview](../en/index.md)。


本轮修复导览中按钮名称与真实落点不一致的问题，保留三模式已有内容与完整模式存档。

## 修改

- 完整模式 11 课使用明确的功能动作：白板首页、工作区分栏、暂存箱收发、组织分栏、OneGO! 收藏、插件、外观与布局、课程、数据与同步。NFC 一课说明先打开收发入口，再点接收查看设备支持。
- 实用模式「展开更多功能」真正展开可搜索的功能目录。OneGO! 的定向打开会清空旧搜索，避免工作区被旧筛选结果盖住。
- 继续导览会关闭练习弹层；从设置重放时清理旧练习状态。体验设置时切换模式，导览自动从新模式第一课继续。
- 极简与实用的接入末页隐藏高级 MCP 开关；完整模式保留，重放时读当前保存值。切换导览不会清除完整模式 MCP 设置。
- 悬浮球文案改为说明 OH 设置入口，删除与现有行为矛盾的「默认关闭」。本轮不改变悬浮球存档、默认行为和原生启动逻辑。
- 六个新增课题补上对应图示，工作区、插件、外观等课程不再复用今日待办示意。

- `tools/experience-browser-test.mjs`：保留原有模式存档隔离、组织、分享、实用入口持久化和 390/320 布局覆盖，旧导览标题已跟上现状。最新一次完整重跑 83 条功能断言通过、页面异常为空，浏览器清理自然完成且进程 exit 0；`docs/onegui/experience-mode/report.json` 已记 `passed: true`。
- 浏览器夹具隔离开发服务器热更新；清理时取消路由、释放请求上下文，再关闭浏览器。超时明确记失败，不强制退出冒充成功。
- 桌面类型检查、导览静态护栏通过。NFC 仅验证收发界面与设备提示，未进行真机碰一碰。

## 后续体验打磨需求（历史登记，本批已完成实现）

用户补充：目前导览仍然简陋，希望更细致的动画优化、三种模式分别适配的引导，可探索流畅的 3D 与流体视觉。这作为后续独立体验批次，本次只登记需求，不把现有功能落点验收当作视觉品质完成。

本节记录最初的需求登记；最终实施和视觉取舍见 [三种模式的空间导览与交互演示](2026-10-20-onboarding-motion.md)。当前主线已调整为极简两课、实用三课、完整五课，原完整模式其余六课保留在「继续探索」。最终采用真实 3D 模型与连续运镜，撤去后续试验过的粒子和霓虹光轨；CSS 立体卡片也仅保留为图形降级。最终验证见 [验收记录](../onegui/onboarding-motion-2026-10-20/README.md)，上文数量只代表此前的功能落点批次。

- **极简模式**：最短路径说明五个 OneShot 入口、今日待办与课程、OH/搜索；简短演示即可进入使用，不引入完整模式概念。
- **实用模式**：围绕常用入口、自定义快捷按钮与「更多功能」组织情景引导；让用户实际完成一个常用操作，再按需了解更多。
- **完整模式**：优先围绕白板、暂存箱、口令、NFC 碰一碰、组织做连续交互演示。其他功能轻量介绍，避免所有主题一视同仁地逐页讲解。
- **视觉与动效候选方向**：模式选择卡的轻量 3D 层次；示意对象在步骤间连续变形与移动；暂存箱收纳、口令传递、雷达/NFC、组织卡片具有对应的空间动效。流体效果服务于操作关系和状态变化，具体渲染技术待原型验证后选择。
- **实施要求**：复用 OneGUI 的组件与动效令牌；能跳过、返回、重播，动作仍可到达真实功能；尊重减少动态效果设置，手机上验证帧率、触摸、文字可读性和遮挡。
