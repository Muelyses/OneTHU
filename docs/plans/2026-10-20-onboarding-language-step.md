# 导览第 0 步：语言选择

先用固定的中英双语询问语言，再选择使用模式、进入该模式的导览。中文和英文并列显示，语言选项读取 `availableLocales()`，用词典自己的名称呈现；不展示没有接入词典的语言。选中后立即保存全局语言，不刷新、不重置模式或已有数据。后退与重放均可回到第 0 步。

采用现有 OneGUI Modal、Radio 和导览配方。第 0 步没有演示画面，内容滚动而继续按钮常驻。章节标题和模式简介补齐词典接入，其他语言接入新词典后自动成为候选项。

验收：首次打开、重放、返回、更改语言后进入三种模式；语言持久化与刷新恢复；第三语言词典通过隔离浏览器 fixture 验证；320px 手机和桌面布局、键盘选择与焦点；i18n 再生成、全量检查、类型检查、现有导览测试。
