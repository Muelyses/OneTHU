# 作业显示、i18n 与全量质量修复顺序

2026-10-20，工作分支 `exp`。本文保留修复顺序，并更新本轮交付状态；翻译质量和真实账号/设备验证不能用本地工程检查代替。

## 1. 先完成三模式作业和同步修复

用户最新确认：同一周完整模式能看到作业，极简、实用模式在列表里能看到，但时间轴看不到；列表下方的作业不能滚动到。这要求验证真正的可见区域和输入命中，不能只断言 DOM 中存在作业。

本轮排查发现：

- 简洁壳在电脑端也把 OH 栏放在底部，但日程配方清掉了底部净空。晚间截止卡片和列表末尾可被常驻栏覆盖。
- 原浏览器夹具只放了下午作业和空课表，点击会自动滚动；不能证明真实晚间作业没有被遮挡。补充短窗口、23:59 截止、长列表、原始输入和命中位置检查。
- 完整模式的隐藏标签仍挂载。它的高度为 0 是正常现象，不能当作当前简洁页面塌陷的证明；调试日志必须结合可见面板判断。
- 网络学堂分项请求失败被吞成空数组，完整作业快照可能被假成功覆盖。独立修复取数失败和旧请求回写，并验证失败时保留完整旧快照。
- 日历、系统镜像与邮箱存在账号隔离、就绪时序、并发写入、错误吞掉等问题，分别见本轮检查报告。数据不完整时禁止破坏性覆盖。

验收要求：三模式，Chromium/WebKit，桌面短窗口和手机尺寸；晚间作业无需自动滚动就能命中，长列表可用滚轮到达最后一项并点击打开；导航来回后仍成立。模拟浏览器和隔离协议测试不能冒称真实手机或学校服务在线验收。

状态：代码修复与本地矩阵已完成，新增布局 313 项通过；同步真实账户写入、原生手机操作仍未执行。详见 [本轮验收](../reviews/2026-10-20-schedule-sync-acceptance.md)。后续不再沿用“快照测试通过就等于用户可见”的验收方式。

## 2. 工程先完成 i18n，再交小模型翻译

详见 [工程接入与翻译文件指南](2026-10-20-i18n-engineering-and-translation-plan.md)。

当前 `exp` 已按最新业务实现接入 i18n，提取完整表达、接语言订阅与格式化、覆盖 OneGUI 默认文案、修复已打开弹层的文案刷新，并建立拒绝缺键、参数与越批修改的验证器。没有合并 PR 57 的旧业务文件；仅复用中文完整匹配的候选译文。

目标词典、只读批次、上下文和命令已存在，见 [翻译指南](../i18n/TRANSLATOR_GUIDE.md)。小模型只修改指定词典值；英文仍有待译空值。网络学堂官方英文课程名仅用于显示，选课和学堂解析补充中英文兼容，未替用户写学校语言偏好。

## 3. 分领域做软件整体审查并修复

优先处理可能导致越权、数据丢失、凭据泄露和跨账号混用的缺陷，再处理稳定性、功能矛盾和废弃实现。每项记录复现、根因、改动、验收及剩余限制。

| 领域 | 必查内容 | 完成证据 |
| --- | --- | --- |
| 身份与权限 | 学校登录/SSO、OAuth/Token 生命周期；组织成员、文件、项目、公告与分享的服务端授权；退出/切账号后的旧请求 | 跨账号与角色失败路径测试；无第二账号时保留真实联调入口并明确未验收范围 |
| 隐私与凭据 | 日志、错误提示、调试导出、剪贴板、口令分享、缓存和持久化中的密码/Token/个人数据；邮件正文与附件 | 数据流清单、脱敏回归；只检查必要字段，报告不复制真实凭据或用户内容 |
| 网络与账号稳定 | 429/超时/取消、单飞与有界重试、会话恢复、前后台切换、离线/半成功、账号 epoch、请求队列 | 模拟失败/恢复和乱序响应；真实服务操作单独标注 |
| 本地与云同步 | 版本/冲突、条件写入、并发编辑、部分失败、持久化错误、删除与同步竞态、重复任务 | 失败保留副本、可重试、无错误清空；原生设备验收单列 |
| 外部输入与原生边界 | HTML/Markdown/邮件渲染、URL 打开与跳转、文件路径与附件、插件/IPC/能力权限、远端资源地址 | 针对边界的恶意输入测试；拒绝越权与凭据跨域转发 |
| 整包更新与发布链 | 已有更新源、传输、取消、大小/哈希校验、安装入口和签名口令处理 | 本地真实 HTTP/文件系统故障测试、跨平台编译；正式资源热更新已按用户后续指示移出本轮 |
| 功能与模式一致 | 三模式数据保留、导览直达、权限提示、待办/作业/日程口径、导航与工作区、暂存箱/口令/NFC | 从用户入口操作验收，不只调用内部函数；切换模式不改数据 |
| OneGUI 与可访问性 | 令牌与样式来源、层级/遮挡、滚动、长文案、主题对比度、键盘/触摸、Windows/WebView 布局 | 桌面/手机尺寸和平台矩阵；截图、命中与实际操作记录 |
| 废弃代码与工程质量 | 重复状态源、旧样式、退役订阅、无调用入口、过期依赖、无效测试、构建/护栏 | 先证明无调用/无迁移依赖再删除；保留存档兼容；完整构建与有效回归 |
| 性能与资源释放 | 首屏包体积、后台轮询、重复请求、页面/窗口退出后的订阅、缓存上限、附件与大列表 | 实际测量与释放检查，避免用无限缓存或无限重试换取表面稳定 |

真实双账号组织联调目前缺少第二账号，用户已明确允许先完成实现并保留入口。不得因此宣称跨账号实测完成，也不因此暂停其他可执行审查。

安全审查按实际覆盖范围报告，不能用“测试全绿”或笼统“全部安全”代替证据。最终列明已修复项、未复现项、环境阻碍和仍待真实设备/账号验证的项目。
