# 完整模式首次首页与默认模板一致

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../README.md)；英文入口见 [English overview](../en/index.md)。


用户反馈 Windows 首次打开完整模式首页很拥挤，主动选择首页模板后恢复。

## 排查与修复

干净存储的 Chromium 首次首页和默认模板像素坐标一致。发现旧导览会预写注册表默认布局，首次创建白板因此被误认为有用户定制，走旧四格主栏/窄侧栏迁移；已创建的旧自动默认白板也不会再升级。

- 首次创建白板时，未保存布局和旧导览写入的原始注册表默认布局都直接使用 `homeStarterItems()`，与默认首页模板同源。
- 已保存布局仅在条目身份、规格、像素位置/尺寸、手调标记、折叠等都吻合历史自动默认结果时修复。兼容旧网格补像素与注入首页组件的两种执行次序。
- 横竖屏独立判断；移动过 1px、删除、折叠、固定、透明度或自定义规格的布局保留，不根据 ID 单独猜测。
- OnePage 与其他模式保持原有行为；正常默认首页加载幂等。

## 验证边界

运行白板模型、重置、模板回归及 TypeScript 检查。浏览器测试加载真实页面，注入旧自动默认文档后重新加载，再点击真实“模板 → 默认首页”，对比初次和手动套用的像素布局，并在 1280、1024、900 CSS px 截图核查。平台标识为 Windows，执行环境为 macOS Chromium，不能替代 Windows WebView2 实机验证。
