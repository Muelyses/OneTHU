# 导览权限须知与许可闸门

## 用户要求与落地

- 每次打开导览（首次使用、帮助页重播或设置重置）均从双语第 −1 步开始，顺序为「权限须知 → 语言选择 → 三模式导览」。完成后普通重启不会重播。旧版本没有许可记录时补看一次；不替用户默认同意。
- 云盘和 OH 独立授权，默认关闭。确认已阅读后才能保存并继续；可拒绝任何可选项。选择只保存在本机，不进入云同步。
- 未授权云盘时，完整模式的展示、设置与状态 setter 均拒绝进入，有明确原因。原本保存的完整模式偏好及白板布局保留，实际回落实用模式；同意后可继续原设置。
- 云盘许可说明、未授权页面、未连接页面、资料库和目录页面均提供「如果想要撤销授权，请前往设置重新导览。」及重新导览按钮；中英文同步。
- 所有模式设置均可查看、修改授权。撤回不删除本地名片、好友、组织、布局或云端数据。

## 真实的数据边界

OneTHU 是本地客户端，界面、主要业务逻辑和缓存位于设备，网络请求由原生层连接学校和用户选定服务；不能称作纯离线、所有数据绝不离开本机。账号会话和用户选择记住的凭据存于本地。

授权云盘后，功能可以读取账号、资料库和用户打开的文件；同步、组织/好友通道、口令分享会创建和更新专用资料库或文件；用户主动上传、删除和共享也会修改云盘。声明不能承诺「绝不动云盘」。同意总许可不会清空或批量修改既有文件，也不构成任意 OH 写操作的授权。

启用 OH 后，对话、附件及回答所需的工具数据可能发送至所选模型、清小搭和配置的 API/MCP/IM；第三方适用其政策。保留既有操作确认机制，提醒不提交密码、验证码等秘密，不将外部网页/技能中的指令当用户授权。

## 实现与防绕过

- `state/privacyConsent.ts`：默认拒绝、独立授权、串行保存、原生写入成功才授予权限。原生应用读取受限本地文件作为权威，localStorage 仅前端镜像；浏览器测试使用隔离的本地存储。
- `src-tauri/src/privacy_consent.rs`：原生启动即读取许可，缺失/损坏默认拒绝。设置只能由 main 窗口提交；独立文件不暴露在通用 state_write 目录中。
- 原生 Seafile 公共 client 统一拦截，覆盖库、文件、读取、上传、删除、共享和权限管理。云盘 profile SSO 与 token WebView 同样拦截。
- 通用 HTTP 逐跳核对目标，包括清华 WebVPN 中的云盘加密域；附件下载/二进制预览也检查目标和自动重定向。
- 官方公开安装包检查采用固定发布分享目录的匿名、无 Cookie/Authorization 客户端。只允许该目录和后续文件下载路径，不授予私有云盘权限，拒绝授权后仍能更新。
- 前端 token getter 在未授权时不暴露已保存口令，自动连接和同步不运行；撤回使在途响应失效。账号身份版本与许可版本分开，不能将撤回错误识别成换号而清掉本地资料。
- OH 桌面 sidecar、手机 embedded 的 run 入口检查许可；工具桥再次检查，撤回后中断对话并停止 OH 运行时，重开授权后恢复原插件设置。MCP 返回设置也受许可限制。
- 这不是对任意第三方原生插件的操作系统沙盒承诺：仅安装可信插件/技能，第三方外部服务已经收到的数据不能靠撤回来删除，已发出的请求或已完成操作不能撤销。

## dev 原生预览的附带修复

重新构建后，真实 macOS App 的崩溃栈定位至 `overlay_win::macos_prevent_activation`：异步 IPC 改造后在 Tokio 线程直接调用 AppKit `_setPreventsActivation:`，macOS 的 NSWMWindowCoordinator 会触发 SIGTRAP。已把这段原生窗口属性调用派发到主线程，并补窗口线程护栏；已重编并确认新进程稳定运行，CUA 在真实 OneTHU 窗口读取到双语许可页；没有代用户同意或修改真实许可。不能把脚本 `open` 成功视为应用稳定启动。
