# OneTHU 0.11 README、官网与文档实施计划

> 历史记录 / Historical record：本文保留当时的计划、研究或验收证据，不代表 0.11 当前能力全集。现行说明见 [文档入口](../README.md)；英文入口见 [English overview](../en/index.md)。


> 当前实现与验收记录随本批更新；计划不代表已发布能力。

**目标**：将 README、官网和全部现行用户/开发文档更新为 0.11 的实际行为，提供仅使用模拟数据的手机竖屏、横屏与大屏预览截图。

**架构**：主仓维护文档、模拟数据采集器、截图来源清单与截图资产；独立官网仓维护可自定义外观的产品说明、滚动三维设备展示与中英文 MkDocs 导航，严格沿用原版上下 Logo。现有计划/审计/设计研究作为历史记录保留，增加明确状态及当前说明入口，避免历史方案被误读为已实现。

**技术**：真实 React/OneGUI 组件 + Playwright 隔离数据，静态 HTML/CSS/JavaScript，按需加载的本地 Three.js 模块，Material for MkDocs。

- 独立开发者页集中构建、Harness、插件、技能和 API，展示全部贡献者；代码新增严格超过 10,000 行者标记主要贡献者，公开统计口径与时间。
