## 云盘镜像与下载链路（已纠正目录约定）

固定分享：https://cloud.tsinghua.edu.cn/d/56f78a2a0b144a6ab737/ 。正式布局沿用 `/Android/`、`/macOS/`、`/Windows/`，各目录保留 0.10 与 0.11；根目录提供 `SHA256SUMS.txt` 和 `latest.json`。撤销误建的 `/v0.11.0/` 副本目录。之前“每版一个文件夹”的记忆错误，不得再沿用。

- 官网中英文下载页按系统展示版本、架构、大小，主按钮直接下载对应云盘安装包，副按钮 GitHub，另有目录、校验文件与逐包 SHA256。首页也有云盘下载入口。无需 JS 可用。
- `tools/check-release-mirrors.py` 匿名读取三个系统目录，按数字版本选择最新安装包；必须与 GitHub Latest 版本、大小、SHA256SUMS 和 Release digest 一致；完整下载三个云盘包核对哈希，再核对双源 `latest.json` 的平台路径、版本及哈希。缺失、落后或不一致即失败退出。
- 官网 Pages 在发布前运行上述检查、刷新 `assets/downloads.json`、重新生成页面。每日定时或手动部署也重新检查，页面注明核验日期。无跨域凭据或临时 seafhttp 下载地址。
- 发布准备：运行 `python3 tools/check-release-mirrors.py --manifests <输出目录>` 生成双源清单（此参数仅生成待发布清单，不检查线上旧清单）；将 cloud-latest.json 作为根目录 latest.json 上传云盘、github-latest.json 作为 latest.json 上传 Release 后，再运行不带 `--manifests` 的完整发布门禁。
- 发布门禁：`python3 tools/check-release-mirrors.py --output ../onethu.github.io/assets/downloads.json`。无云盘 Token、无账号登录，只用公开分享；GitHub 限额需要时可传 `GH_TOKEN`，仅发给 api.github.com。
- 夹具验证：`python3 tools/check-release-mirrors-test.py` 覆盖版本排序、缺包、旧版本、大小错误、哈希错误等拒绝路径。
- 实际更新器验收：`node tools/update-sources-live-test.mjs` 提取真实 updater.ts 代码，仅将 Tauri HTTP 桥替换为只读网络适配；三个平台双源清单及 GitHub 失败后的云盘回退均通过，`hashAvailable=true`。未触发下载安装 IPC。
- 官网浏览器验收：`node tools/site-download-browser-test.mjs`，320/390/768/1440 宽度、中英文、禁用 JavaScript 的 8 组布局，检查直达路径、按钮尺寸、无水平溢出、展开哈希。截图在 `/Volumes/OneTHUBuild/artifacts/release-0.11/download-page/`。

双源 latest.json 是当前已有下载更新器的清单，不涉及热更新或应用代码改动，因此无需重打三端安装包。

官网修复提交：`OneTHU/onethu.github.io@567910f`。部署与云盘发布门禁：[Pages run 39562462694](https://github.com/OneTHU/onethu.github.io/actions/runs/39562462694)。公开目录 API 不提供跨域 CORS，因此由 Pages 构建环境直接核验云盘并生成可无 JS 使用的下载链接，而不让浏览器发必被阻止的跨域请求。
