# Unified Resident Runtime Implementation Plan

**Goal:** 桌面、OH、CLI 使用同一登录身份、任务记录与后台调度器，关闭桌面后已授权任务继续执行。

**Architecture:** 独立 Node daemon 持有本机唯一运行时和 profile。桌面通过仅主窗口可调用的 Rust 私有桥接连接 daemon，OH 复用桌面服务入口。已有校园 UI 客户端从可信接口恢复同一会话；成功登录、切换账号、退出登录均带 epoch 栅栏移交，后台成为认证与任务状态的权威来源。

**Tech Stack:** TypeScript/Node SDK、HTTP JSON-RPC loopback、Tauri/Rust、React/OneGUI。

## 决策与边界

- 采用后台统一所有者。共享文件但保留两个调度器会产生竞态；关闭桌面时临时搬任务会在退出异常时丢失交接。这两种方案均增加故障路径。
- 本机标准 profile 沿用 `OneTHU CLI`，现有独立 CLI 可直接使用；用户显式 `--data-dir` 创建的隔离 profile 保持隔离。
- Node 随桌面 macOS/Windows 安装资源分发，校验平台、架构和官方 Node 校验和。Android 保留原有应用内运行时。
- GUI 不获得 daemon 发现令牌；主窗口 Rust 桥接从私有发现文件读取。认证快照只经可信本机 `desktop.*` 接口，MCP/插件服务目录不暴露该接口。
- 持久 epoch 和明确登出标记阻止旧 GUI 缓存复活登录。bootstrap 仅用于首次移交；明确登录可在核验账号后切换。密码继续遵守已有存储策略，不复制到独立会话快照。
- 旧任务按 ID、执行历史、已发送/下载账簿迁移，记录迁移来源；冲突保留两侧数据并返回问题。桌面停止调度后才由后台运行，绝不同时启动两个 manager。
- OH/CLI 执行权限由同一设备策略控制；关闭窗口不改变授权。撤销授权、退出账号立即停止在途任务。
- 现有 IM 通知凭据迁移只用于后台出站通知，本轮不再启动一套并发 IM 入站轮询。绑定收件人参与通道标识，迁移核验目标一致。

1. SDK：`src/node/session.ts`、`src/index.ts`、任务与通知模块，增加可信桌面接口、身份导入/导出、迁移幂等与持久登出；测试旧快照、跨账号、并发登出、去重历史、目标绑定。
2. CLI：`src/daemon.mjs` 私有 desktop 方法分派与协议/构建身份探测；测试 MCP 不可访问快照/配置、未知方法拒绝、截止时间与断连取消。
3. 原生桥接：`apps/desktop/src-tauri/src/cli_daemon.rs` 主窗口限定、发现文件权限校验、独立进程启动与版本协调；构建资源包含自足 Node+CLI。
4. 桌面：`state/cliTasks.ts` 桌面分支统一代理，`lib/clients.ts` 恢复/登录/登出接入，`state/cliRuntime.ts` 共享策略，OneGUI 展示实际后台状态；Android 保留现有路径。
5. 旧任务/IM 配置迁移：迁移成功后记完成，失败保留原始存档与错误；已有后台冲突不静默覆盖。
6. 完成 SDK/CLI/native/desktop 相关检查，重新构建 dev 与后台，验证同一任务从 GUI 与 CLI 可见、App 退出后 daemon PID/任务历史仍可用，并重新打开桌面恢复同一账号。
7. 更新中英文使用文档和记忆，明确实机验证范围。无版本发布、无实际预约/邮件/IM 测试发送。

### 已确认的原因与修补

- SDK 曾过滤全部 `wengine_vpn_ticket`；其中 `wrdvpn1-` 前缀也会用于有效 HTTP 会话。现在保留服务器与可信快照中的网关票，并以学校只读身份接口核验账号。
- Info 的 Cookie 接口在首次打开该服务前可能返回空正文。核验增加一次只读入口预热，随后重取 Cookie；无法核验时保留原会话。
- Info 刷新正文与 HTTP Cookie 曾写入不同路径，旧应用路径值会压过新的根路径值。InfoClient 与身份核验现在共用解析器，更新逻辑域和 WebVPN 应用路径，正文无法覆盖网关票或注入 Cookie 属性。
- GUI 原先只导出 JavaScript Cookie，遗漏原生网络层的完整状态；恢复时又清空原生仓。新增仅主窗口可用的完整导出、按版本校验的原子导入，原生写盘成功后再更新两份 JS jar 与本地会话镜像。
- 学校登录成功与后台移交状态分开处理。待移交意图持久化，临时后台失败保持 GUI 登录并允许无密码重试；明确登出、账号变化以版本栅栏淘汰旧意图。后台延迟恢复成功后强制完成界面水合。
- 实机首次调用 `learn.courses` 进一步暴露了移交后 CSRF 尚未准备的问题。补充统一、可重试的只读 Learn 初始化；不重放业务写操作。进程退出以关闭标志和网络取消隔离旧请求，账号版本保持持久稳定。
