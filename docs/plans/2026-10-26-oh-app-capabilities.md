# OH 应用能力接入

用户连续发现雨课堂、好友、组织无法由 OH 正确发现，并要求同时审查清小搭及其他新功能。原有专用工具覆盖学校接口与白板、插件等能力，但好友、组织、技能广场、暂存箱缺少公共查询；已启用技能搜索也不能代表整个清小搭广场。

通过同一已审核服务目录提供 OH 的 `app_services` 发现和 `app_call` 调用，复用 CLI 参数校验、账号代次、结果去凭据与写操作确认。应用内部调用不依赖用户开启对外 CLI 监听；任务等后台能力继续核实自己的 CLI 授权。新功能必须登记公共目录才可调用，禁止任意命名空间透传。每轮注入宿主真实提供的操作名，让模型根据当前能力核实，保留已有专用工具。

补齐 OneTHU 好友名片、组织概览及成员／项目／公告／资源引用、清小搭智能体与技能广场／已安装技能／导入启停、暂存箱摘要与文本内容。好友和组织数据按当前账号、完整模式及个人资料归属核验，组织远程详情验证实时成员权限。名片与组织分享口令、通道与邀请凭据不进入模型。已有学校、白板、OneFlow、插件、主题与常驻任务工具一起列入报告；复杂图形编辑、扫码和系统权限继续通过页面直达。

验收覆盖真实好友问题、组织问题和技能能力发现，同时验证缺权限、账号切换、模式切换、无效参数、确认取消、敏感字段过滤。保留原 CLI、雨课堂与附件修改，不发布安装包。
