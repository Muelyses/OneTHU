# OneTHU 0.11.4 发布计划

**目标：**完整保存当前 main 工作区，让 dev3 与 main 指向同一份源码，发布 macOS、Windows、Android 0.11.4 并核对更新渠道。

**方案：**先提交 Harness 子模块，再提交主仓库；dev3 使用快进对齐，保留历史。桌面通过同一标签的 Actions 构建，Android 使用本地正式证书。以同一提交、构建 run、文件摘要绑定产物。

1. 核对版本字段、CLI/SDK 构建接入、生产身份；排除本地凭据、构建产物和临时探针。
2. 完成发布说明与验证：认证、云盘边界、CLI/SDK、OH、新接口、i18n、TypeScript 与前端构建。
3. 推送 Harness，提交 main，快进 dev3；为冻结源码创建 v0.11.4 标签并触发桌面构建。
4. 本地签名构建 Android，验证版本 0.11.4 / code 11013、签名、Logo 与嵌入前端；下载并核对桌面产物和 CLI 运行时。
5. 上传 GitHub 草稿和既有清华云盘系统目录，更新校验码与 latest.json；核对后公开 GitHub Latest。
6. 更新官网中英文版本、文档与下载快照；完整下载三平台镜像验证摘要，记录发布证据与长期记忆。

验收边界：静态验包和协议测试分别记录；不将其表述为 Windows/Android 真机登录验收。模型端 502 属于服务可用性，另列当前状态。
