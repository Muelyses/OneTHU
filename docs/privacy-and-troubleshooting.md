# 隐私、账户与故障处理

中文 · [English](en/privacy-and-troubleshooting.md)

## 数据流与存储

| 内容 | 位置与用途 |
|---|---|
| 登录状态、记住的凭据、API 配置 | 本机存储；相应服务请求使用对应凭据 |
| 白板、模式与布局 | 本机设置与应用数据；切换模式保留完整存档 |
| 个人名片、好友与组织索引 | 完整模式连接云盘后可同步到私有 OneTHU-Profile |
| OH 记忆 | 按配置使用 OH-Memory，与个人资料同步不同 |
| 分享内容 | 按分享操作上传清单/文件并设置可访问范围 |
| OH 对话与工具上下文 | 发送给当前选用的模型服务 |
| 清小搭技能 | 本机账号分区；启用后相关资料可进入模型上下文 |

本机混淆或密文存储不能代替操作系统账户隔离。能读取应用数据和相应密钥的人可能恢复凭据。个人资料同步不上传密码/API Key，组织索引也不能代替 GitLab/云盘授权。

## 登录、公钥与信任设备

「公钥获取失败」可能来自缺失/异常页面、网络错误、服务限流或信任设备限制，不能仅凭该短句认定学校系统故障。0.11 修复了设备认证指纹与保存值不一致、无条件第二次登录和部分 2FA 时序问题，并增加分类诊断。

新登录链执行 20 秒冷却，同一轮并发提交共用一条链，刷新不会重置本轮计时。输入验证码继续既有认证，不应重新清空登录链。发码失败会保留失败状态；验证码失效时按提示重新开始。

信任设备达到上限时，本次认证仍可能继续，只是不保存新的信任记录。应用不会自动删除学校设备；管理旧设备须在学校相应服务中操作。

## 刷新与网络

强制刷新按钮短按执行刷新，长按用于移动按钮。刷新不等于清空凭据、解除限流或更新安装包。TUN/代理可能改变 DNS、路由或证书链，但关闭 TUN 后仍卡住不能归因于代理；应结合版本、平台、请求阶段和错误状态判断。

Windows 0.11 修复过 WebView 在错误线程创建导致的界面不可点击问题。窗口能拖动但所有网页控件不可点时，优先记录构建版本与运行日志，而不是持续重复提交密码。

## 云盘归属与资料同步

当前云盘元数据兼容群组/共享库的字段差异。目标个人资料库归属未知、旧宿主缺能力或存在共享/虚拟子库限制时，相关自动建库、删除和同步会停止。该保护不表示用户必然没有写权限，也不应通过隐藏警告强行删除资料库。

跨设备资料先在保留本机存量的设备更新并同步，其他新设备才能取回。自动合并只处理兼容修改；真实冲突必须明确选择一个版本。账号切换与模式切换会阻止旧异步结果写入当前资料。

## 反馈与诊断

反馈包含应用版本、构建信息、平台、触发步骤和脱敏诊断摘要。诊断记录请求状态、脱敏路径、页面长度和错误阶段，不需要密码、验证码、Cookie、完整认证网页或 API Key。剪贴板不可用时，界面可显示可选择的诊断文本。

| 现象 | 核对入口 |
|---|---|
| 数据空白或过旧 | 当前页面刷新、服务登录状态、筛选条件与学期 |
| 作业 DDL 未显示 | 相同日期的作业列表、日程来源开关、截止时间解析 |
| 同步资料为空 | 当前账号、旧设备是否上传、模式、资料库归属 |
| 通知未到 | 系统通知权限、精确闹钟、静默时段与厂商后台限制 |
| NFC 不稳定 | 优先短口令；核对设备与原生构建支持 |
| 技能不能启用 | 实际依赖与兼容性；不支持时导出给电脑 Agent |

## 更新机制

开发服务器的前端 HMR、插件更新与应用安装包更新是不同机制。应用没有通用的远程代码热替换后端；更新以实际安装包和插件更新能力为准，不能将开发热重载宣传成生产热更新。
