# OneTHU 0.11.1 · Revolution 修复更新

[中文](release-0.11.1.md) · [English](en/release-0.11.1.md)

本次更新面向 macOS、Windows 与 Android，恢复二级选课课程的展示和同步，并集中修复手机操作。

- 二级课表兼容学校中文与英文周次（含 `week 4`），恢复语言切换后遗漏的课程。
- 校历加载完成后，时间轴自动补齐二级课程，首次打开即可继续显示。
- 月历列表加入二级课表，课程日期、时段和详情与时间轴保持一致。
- 二级课表刷新异常时显示重试提示，其他课程继续展示。
- 系统日历使用新版完整学期缓存，按校验后的一级与二级数据同步，失败时保留已有内容。
- Android 版本号为 0.11.1，versionCode 11009，沿用原正式签名与上下结构 Logo。

安装新版后，在日程设置中刷新即可重取课程。自动更新检测、GitHub 下载和清华云盘镜像随本次发布更新。

工程验证及复跑入口见 [二级课表修复报告](reviews/2026-10-22-secondary-schedule.md)。

## 手机操作与布局

- 手机可选择底部 OneShot 或左上角按钮展开的纵向导航浮层：极简展示五项，完整和实用展示全部一级功能区。三种模式分别记忆设置；完整和实用导览提供布局选择。
- 进入白板编辑保留当前缩放与布局；编辑入口更清楚，增加撤销上一步、确认恢复默认。
- 暂存箱拖到屏幕边缘后吸附并半收起，点一下打开，拖回中间可自由放置；传输时完整展开。
- Android OH 悬浮窗的收起按钮使用更醒目的图标、文字和高对比样式。
- 从个人名片、组织设置进入组织管理时关闭设置浮层，目标页面和编辑表单可直接操作。
- 检查更新保留加载文字与动画，自动切换主备源，提供超时、取消和重试；三种模式均可检查更新。

移动端浏览器触摸验收与限制见 [手机修复报告](reviews/2026-10-22-mobile-repair-round3.md)。

## 10 月 22 日安装包修订

组件预览改用独立只读数据作用域，示例课程、作业和课件保留在预览内部，真实搜索与后台刷新读取账号数据。三端安装包统一纳入此修复。

已安装旧 0.11.1 的用户请重新下载并覆盖安装，保留用户数据。旧客户端按版本号比较，相同版本号的安装包修订需要手动下载。Android versionCode 已升至 11009。详见 [预览数据隔离报告](reviews/2026-10-22-preview-data-isolation.md)。
