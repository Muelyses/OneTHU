# 0.11.3 登录与更新修复

[中文](release-0.11.3.md) · [English](en/release-0.11.3.md)

OneTHU 0.11.3 · Revolution 面向 macOS、Windows 与 Android。此次更新集中处理登录恢复、设备身份和登录界面的更新能力。现有正式版支持覆盖升级，保留本机数据与设置。

## 登录界面也能更新

打开应用后，登录界面可以显示新版公告。选择“前往更新”可在独立弹窗中查看安装包、下载进度并确认安装，无需先完成学校登录。登录页和二次验证页同时保留“检查更新”入口。

极简、实用和完整模式共用此能力，中英文界面均可使用。自动提醒避开正在进行的登录与验证码输入；用户主动检查更新后，原有输入继续保留。公告单独滚动，提醒可延后 1 小时、1 天或 7 天。

## 学校服务异常时的恢复

会话检查区分明确失登与网关引导页、限流、服务故障及网络错误。已保存账号遇到临时服务故障时保留本地视图；明确失登后才进入登录流程。探测超时后继续观察原请求，避免启动并行的密码登录。

登录准备阶段遇到短网关页面，会提供具体的稍后重试提示。错误诊断包含分类与处理阶段，密码、验证码、Cookie 和网页正文继续省略。学校服务恢复后可再次尝试登录。

## 设备身份和账号归属

同一安装的设备指纹在并发调用、刷新和本机存储恢复时保持一致。同账号重新登录复用已知会话；换账号、归属不明或退出登录时执行隔离。学校“本次统一登录”选项改为显式选择，验证码验证中的信任设备选择继续保留。

此次调整减少由重复恢复和设备身份变化带来的认证请求。学校已有的信任设备记录仍由学校统一认证管理；如达到上限，可在学校官方管理页面处理。

## 安装包

Android 沿用正式签名和原版 Logo，versionCode 为 11012。GitHub Releases 与清华云盘镜像提供各系统安装包和 SHA-256 校验信息。
