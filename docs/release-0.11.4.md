# OneTHU 0.11.4 · Revolution

[English](en/release-0.11.4.md) · [下载](https://github.com/smartThise/OneTHU/releases/tag/v0.11.4)

此次更新把 CLI、常驻任务与 OH 的应用能力连接起来，并收录近期登录、云盘、附件和界面修复。

- **OneTHU CLI 与 SDK：**可独立安装；macOS、Windows 桌面内置 Node 运行时，共享登录、任务及执行历史。已授权后台任务可在 App 关闭后继续运行。支持课程与资料查询、归档、定时检查、通知及 MCP 接入。具体能力以当前命令目录为准。
- **OH 工具：**加入应用能力目录及调用接口，可查询 OneTHU 好友、组织成员和资源，管理项目与公告，检索清小搭技能、向已选智能体提问，并读取、收纳及分享暂存箱内容。角色授权等操作保留管理页确认。
- **雨课堂：**统一接入 OH 和 CLI 查询，区分学校会话与雨课堂会话；分页、不完整结果和无截止日期的状态更明确。
- **稳定性：**修复 IM 配置与对话上下文文件冲突、请求取消和运行锁，改善桌面与 CLI 的会话移交、云盘自动连接和账号隔离。
- **学习与界面：**修复通知附件的名称和格式识别；合入玻璃效果、壁纸归档、标签页及 OH 交互优化。

Android 保留移动端内嵌 OH，独立 Node 常驻后台属于桌面能力。应用本地好友、组织、白板和暂存箱接口需运行 App；独立 CLI 的实际目录会明确列出可调用项。重型技能仍交给外部 Agent 运行。

自动执行沿用本机授权策略，修改、分享和外发操作继续经过权限与账号校验。模型回答依赖所选提供方，模型服务错误不会被计为工具成功。

三端版本为 **0.11.4**。Android ARM64 使用原正式证书和 Logo，versionCode **11013**。
