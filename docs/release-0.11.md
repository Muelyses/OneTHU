# 0.11 Revolution

中文 · [English](en/release-0.11.md)

0.11 将界面、工作台与模式选择统一到 OneGUI，并补齐多端导航、个人资料同步、清小搭技能与导览。发布包是否包含最新修复取决于构建提交，不能仅凭相同版本号判断。

## 主要变化

- 石墨默认视觉、主题/密度/材质令牌与文字对比度统一解析。
- 极简、实用、完整三模式；第 0 步选择语言，之后按模式介绍功能。
- 所有模式解释搜索、OneTHU Harness 和插件范围；完整模式补充白板、暂存箱、短口令、NFC、组织、清小搭。
- 完整模式白板、标签页、工作区、OneGO!、可配置 OneShot 与可移动刷新/暂存入口。
- 暂存箱以清晰长按拖入、高亮命中与统一分享入口组织收纳和传递。
- 成员、文件、项目与公告的组织管理；私有个人资料库同步名片、好友与组织索引。
- 兼容变更默认自动合并，真实矛盾用卡片对比并明确二选一。
- 日程合并课程、作业截止与自定义安排，修复紧凑模式截止来源与底部滚动。
- 清小搭对话、历史、智能体、技能广场；OH 可使用兼容的资料与纯 JavaScript 技能。
- 登录设备指纹、防重复认证、20 秒冷却、2FA 时序和脱敏错误诊断修补。
- Android 返回历史、手机胶囊排版、Windows 建窗线程与网络学堂跨平台布局修补。

## 能力边界

**NFC 目前可用性不稳定，请尽量使用口令。** 技能的 Python/Node/外部服务不在当前内置轻量环境中；六份抽查样包均需电脑 Agent。真实双校园账号协作、所有厂商 Android 后台表现与 Windows/macOS 所有硬件组合未完成统一验收。

README、官网和文档中的截图全部采用隔离模拟数据，包含手机竖屏、横屏和大屏视口；不会读取真实校园账号。来源与复现命令见 [预览素材](screenshots.md)。
