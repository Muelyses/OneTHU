# i18n 工程、学校英文兼容与安全修补交付

工作分支 `exp`，2026-10-20。本轮从现有业务继续实现，没有用 PR 57 的旧页面覆盖新版界面；翻译交接和安全审查并行收口。源文键数、候选译文数与批次以 [交付清单](../i18n/catalog.json) 为准。

最终清单为 **7,296 条源文、92 批**；英文有 **564 条待复核候选、6,732 条待填**。`--locale en-US --complete` 实际运行仍按预期拒绝发布，空值没有被计为翻译完成。

## 翻译模型现在负责什么

只填写 `apps/desktop/src/i18n/locales/en-US.ts` 的指定字符串值。入口为 [翻译指南](../i18n/TRANSLATOR_GUIDE.md)、[术语表](../i18n/GLOSSARY.md)、[批次 001](../i18n/batches/001.json)。批次检查要求工程基线，拒绝错占位符、缺键、执行代码、源文版本不一致、越批修改，以及改动业务/测试等其他文件。

运行时已覆盖语言保存、跨窗口、三种模式设置入口、`document.lang`、OneGUI 默认文案、确认/表单/Toast、稳定设置定位和按语言重算的展示值。29 个业务及插件表单入口的固定显示文案改为描述符，已打开的表单可跟随语言更新；默认值、用户输入和选项身份保持原值。切换语言不重挂应用。翻译函数在调用时读取当前语言，回调不因单纯 locale 依赖被批量重建，避免意外重触发请求副作用。

中英文词典具有一致键集；英文空值表示待翻译并回退中文。已有候选译文也要复核。工程接入、英文覆盖率、语言质量是三个不同验收项，当前没有声称英文或其他语言已经翻译完成。

本轮修正了提取中发现的身份边界：THOS 中文状态比较、洗衣机定位、外校课程搜索词、系统日历名称、系统首页持久名称保持原值。导航、搜索和标签的展示文案单独解析；学堂行的 Atom 使用原始课程名，避免在暂存箱产生重复内容。

Android 桌面小组件也接入同一词典：快照携带语言和 62 条模板，原生后台重算继续使用该语言；语言切换会更新快照，并阻止旧异步任务覆盖。另修复了插件槽位存储/读取结构不一致，以及实例枚举失败后仍错误清理已保存内容的问题。见 [小组件验收](2026-10-20-native-widget-i18n.md)。

## 学校英文页面

- 网络学堂有学校自己的语言切换入口和 `englishName` 数据。中文显示原课程名；其他非中文语言优先学校英文名，没有则保留原名；搜索兼容两者。
- 用户第二份附件是 Info 英文门户，不是英文选课内页。解析器补了中英文表头、分页、会话识别和业务拒绝；未知页面不会当作空课表，明确失败不会被旧已选记录掩盖。
- 作业提交只承认明确的机器成功字段；退课与志愿调整需准确身份的回读确认。没有自动修改学校网站语言设置。
- 原始附件包含私人信息，未复制到仓库。使用匿名结构验证，未进行学校登录、真实提交、选课或退课。官方英文内页没有足够实样，不能称为在线全站验收。

见 [学校英文解析与身份报告](2026-10-20-school-language-parser.md)。

## 仍然存在的边界

1. 英文仍待批次翻译；最终长译文、其他语言、实体手机与 Windows WebView2 尚需发布验收。390 视口的浏览器点击不冒充手机真机。
2. 缺少第二个真实账号，组织跨账号联调未执行，入口保留。学校英文选课内页、真实作业提交、学校 SSO 仍无在线验证。
3. 生产依赖审计仍有 Quill 低危、sprintf-js 中危公告。当前两个 Quill 编辑器禁用涉事格式且 HTML 输出消毒；sprintf-js 位于 Mammoth CLI 的 argparse 路径，实际浏览器转换 bundle 未包含它。没有忽略告警，也不宣称依赖零风险。
4. 私有文件权限和脱敏不等于系统钥匙串或全量凭据加密；原生插件仍拥有用户授权的本机权限，并未建立操作系统沙箱。没有静默删除历史日志。
5. 更新清单仍依赖 HTTPS 来源，哈希不等于发行者签名。没有真实系统覆盖升级、签名迁移、断电恢复或原生包事务回滚证据。
6. 安全审查是已列数据流和失败路径的工程检查，不是对全仓或所有未来服务行为的安全保证。打包仍有较大 chunk 警告；没有通过调高阈值隐藏它。
7. 本轮没有生成或安装新的原生包；Rust/Kotlin 的修复需要重新打包后才会进入已安装的 App。浏览器和 Vite 验收只证明当前前端源码。

本轮不发布、不推送、不读取真实凭据，也不修改真实学校账户或云端权限。
