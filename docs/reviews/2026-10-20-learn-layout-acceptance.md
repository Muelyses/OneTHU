# 网络学堂布局与课程快捷入口验收

日期：2026-10-20。使用隔离浏览器和示例课程数据；未登录学校账户，未请求学校接口。

## 问题与修改

- 右侧空白来自正文容器固定的 1160px 上限。本轮仅为网络学堂主列表解除上限，其他正文页保持原布局。
- 旧课程卡传入 `style` 后被兼容组件增加外层容器，网格拉伸外层而卡片高度不齐；旧按钮兼容规则又覆盖了课程内容布局。新课程卡直接组合 OneGUI `Card`、`Btn` 和 `Tag`，样式统一收进 `recipes/learn.css`。
- 课程列宽使用 `--og-grid-min-xl`（320px）和 `auto-fill`，保留长标题、教师及场地的完整换行。手机单列，顶部四个统计入口为 2×2。
- 网络学堂、雨课堂、未交、通知、文件均为独立按钮，0 项时也保留。课程主入口、收藏和各快捷入口没有嵌套按钮。
- 网络学堂快捷入口携带 `courseId/courseTab`；雨课堂携带 `extCourseId/extCourseName/courseTab`。雨课堂新增作业、通知、文件聚合选项，保留全部内容及已有细分类。课程名称合并规则未变。

每个组合检查课程数量、同名合并、不丢独立雨课堂、卡片等高、长文本无裁切、无横向溢出及旧样式移除。1280 宽度实际点击各来源与内容入口，并用 Enter、Space 验证键盘操作。390 宽度使用真实触摸输入，逐个验证入口。

未匹配的雨课堂放在列表最后，三个内容计数均为 0：滚动后验证按钮中心实际命中，触摸打开课程，并确认对应 OneGUI 分组选项真实选中。固定 OneShot 未遮挡这些入口。

首轮“点击后仍在课程列表”的失败来自测试夹具：页面加载了带 Vite 热更新参数的路由模块，测试却动态导入无参数路径，读到了第二份状态。可信点击事件和可见 DOM 已证明产品成功进入课程页。夹具现绑定页面实际加载的模块 URL，并同时断言活动路由和可见页面，没有放宽点击要求。

脚本另验证了三个错误配置：未知浏览器、空视口、明确指定但未安装的 WebKit，全部在启动浏览器前退出码 1，避免出现零项通过。

已人工查看最终桌面与手机截图：长课名、教师、场地完整，来源与计数排列整齐，最末课程入口可达。
