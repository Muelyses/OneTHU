# 英文官网与导览素材修补

## 问题与实现

英文网页和导览先前只切换说明文案，设备屏幕与演示仍引用中文素材。现为英文界面和英文虚构课程、作业、人物、组织、技能数据单独采集截图及实际长按拖入视频，保留中文文件。没有在截图上覆盖译文，也不接触真实账户。

- 官网、英文 README 和英文文档引用 `en-US` 专属图片和视频。
- 导览 31 个屏幕均有独立英文版本；WebGL 模型、无 WebGL 降级和减少动态的静态画面采用相同语言来源。
- 图片解码缓存按语言隔离；切换语言卸载旧模型及视频，避免旧异步加载完成后覆盖新语言。
- 所有非中文导览语言使用英文演示，中文使用中文演示。
- 新建暂存箱默认名、组织默认成员名、作业/通知/文件的暂存来源、清小搭默认助手名接入现有词典。补齐搜索结果分组、实用模式说明回退与外部作业平台名称的展示层翻译。已保存的用户名称/外部内容不随语言切换改写。
- 采集器使用语言参数、临时上下文、固定模拟时间、外部请求隔离和 SHA-256 清单；英文采集核对可见文字无中文残留。

## 重现

见 [素材采集说明](../screenshots.md)。`ONETHU_CAPTURE_LOCALE=en-US` 配合 `capture-public-preview.mjs`、`capture-localized-tour.mjs`、`record-vault-onboarding.mjs` 采集英文；官网 `sync-preview-assets.py --locale en-US` 校验哈希后生成 WebP。
