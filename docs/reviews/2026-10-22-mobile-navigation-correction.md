# 手机导航更正 · 2026-10-22

## 最终交互

手机可在设置中选择底部 OneShot，或左上角按钮打开的纵向功能浮层。浮层复用 OneGUI Drawer：点选入口后关闭，支持点击背景、关闭按钮、Escape 和系统返回。页面始终保持全宽，OH、搜索、标签页及 OneGO 沿用各模式现有逻辑。

- 极简模式：学习、预约、生活、信息、课表五项。
- 实用与完整模式：沿用 0.10 的图标加名称纵向列表，展示当前全部 16 个内置一级功能区。完整模式还展示已注册的插件功能页。
- 实用模式保留既有能力隔离；需要完整版的入口带标记，点击后进入可切换模式的设置并显示说明。数据与接收隔离逻辑继续保留。
- 三种模式各自保存设备本地偏好，默认底部 OneShot。完整／实用手机导览在选择模式后提供布局选择；极简导览直接进入其功能介绍。三种模式均可从设置调整导航。

更正替换了最初错误的“左侧常驻五个 OneShot 按钮并压缩页面”实现，删除了其页面占位、宽度扣减及专属卡片压缩样式。

## 实现与复用

`MobileFeatureNavigation.tsx` 复用 `Layout.tsx` 的 NAV 单源、现有页面路由和 OneGUI Drawer、Btn、IconBtn，浮层宽度使用既有轨道令牌。设置与导览共用 `MobileLayoutChoice`；中英文词条及静态提取种子同步更新。预览测试关闭上下文前等待请求路由处理结束，避免中断尚未完成的匿名夹具请求。
