# 手机操作与布局修复 · 2026-10-22

本批进入 0.11.1，与二级课表修复一起发布。桌面保留原导航与白板编辑方式。

## 问题与处理

| 反馈 | 原因及修复 |
| --- | --- |
| 检查更新成为空灰按钮 | OneGUI loading 样式同时隐藏文字、清空字色，而 spinner 缺少实际尺寸与绘制。现在保留文字，绘制转圈；检查展示当前源，主源 8 秒、备用源 15 秒上限，支持取消和重新检查，旧请求不能覆盖新结果。 |
| 管理组织、编辑看似没反应 | 设置里的显式导航会在设置浮层后打开目标。增加专用导航方法，先关闭设置；通过真实新建组织流程检查管理页和编辑表单。 |
| 编辑白板突然变成电脑布局 | 编辑条件下的旧效果会把尚未保存缩放的手机自由画布强制放大到 500%。删除此跳变，自由摆放首次使用视口适配 100%，保留既有缩放偏好；Android 使用系统屏幕朝向，输入时保持竖屏阅读布局。 |
| 编辑入口双重方框 | 浏览状态的工具栏移除外层框、阴影、材质，仅显示带笔图标的编辑按钮。 |
| 白板缺少撤销和恢复 | 增加按板及朝向隔离的会话撤销；自动拟合不占一次撤销，连续文字输入合并，外部写入会废弃过期历史。首页恢复默认组件与布局，普通 OnePage 恢复空白；均先确认，恢复操作也可撤销。 |
| 暂存箱挡住内容 | 手机在距边缘 24px 内释放会吸附并半收起；一次点按直接打开管理，拖回中间恢复自由摆放。传输时完整展开，桌面继续自由摆放。点击容差与强制刷新入口保持一致，鼠标 10px、触摸 12px。 |
| OH 收起入口难发现 | Android 原生悬浮窗使用高对比图标和文字，按钮高 44dp；标签跟随界面语言。 |
| 手机需要可选导航 | 完整、实用模式分别保存底部五入口或侧边五入口，设置和导览共用同一组件及状态。侧栏给页面预留实际空间；极简固定底部导航，桌面沿用原流程。 |

手机导览在模式选择后展示布局选择；第一节返回时可再次调整。偏好保存在设备本地，不改动已有白板、OneShot 内容或其他模式设置。实用和极简设置补入软件更新入口。

## 截图复核补充

320px 侧边导航截图暴露了白板 240px 宽度下限造成的卡片裁切。外框宽度检查曾通过，内部组件仍超出剩余空间。已让阅读投影使用实际容器宽度，侧边布局的一级功能区改为三列，并逐件检查组件包围盒；原始文档摆位继续保留。
