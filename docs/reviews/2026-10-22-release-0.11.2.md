# OneTHU 0.11.2 发布执行记录

用户要求在本轮 0.11.1 修订构建期间改发 0.11.2，并将新增交互、新闻语言和手机触摸问题一同修复，再更新三端与所有下载渠道。

## 当前阶段

应用源码、三端构建及最终验包已完成。GitHub Release `v0.11.2` 已公开并设为 Latest；清华云盘三端安装包、校验码和更新清单已同步。三平台实际更新器均通过双源读取和故障回退检查。官网与文档执行独立的下载及部署验收，记录见下文。

此前准备的 0.11.1 本地 APK 作为过程产物保留，公开安装包未替换。`v0.11.1` 已在 GitHub 与校内镜像恢复到实际已发布源码 `7413291a34e3b941a46481f9abafdf0b31dc6770`。两次旧版构建因用户改发版本而取消。

## 本轮交付内容

- 三种模式共用新版提醒弹窗，支持前往软件更新及 1 小时、1 天、7 天后提醒。提醒期限按版本存于本机，重启后保留，新版本重新提醒。
- 更新提示等待已有对话框、导览与实践返回条完成；支持 Escape 和 Android 返回。前往更新直接定位共享更新区域并复用已取得的结果，下载和安装由用户操作。
- 软件更新的来源、检查状态、切源说明和安装提示随当前语言渲染；学校或原生返回的外部错误与发布说明保留来源文本。
- 新闻读取按学校门户的中英文协议设置语言，相关读取串行，首页与新闻页统一数据入口。缓存按语言隔离，迟到的旧语言结果不覆盖当前显示；搜索和订阅详情也恢复当前语言的来源名称。
- 简洁首页删除重复口号，保留今日待办、今日课程标题与内容，日期采用当前界面语言。
- 手机白板确认按钮单独处理触摸手势，小幅按钮内移动可以确认；拖出、明显移动与取消保留取消语义。退场保留当前预览，减少目录重建。
- 包含同日的学习会话恢复、跨设备壁纸媒体备份、横屏平板编辑开关、学习页面玻璃与桌面 OH 单实例修复。

### Windows 单实例的实际代码核验

旧验包脚本要求 `tracing::warn!` 的完整文字，优化后的发布文件没有保留该可选日志分支。检查已改为解析真实 PE 导入表、ABI 参数及分支目标。安装器内 `onethu.exe` 的 SHA-256 为 `4b6cfa7abaef68254e5c20a81c45fd84f983f9aa179b616ae69827116264ee2a`，实际存在 40 次窗口探测、每次 25 ms 等待、`WM_COPYDATA` / `SMTO_NORMAL` / 10000 ms 的 `SendMessageTimeoutW` 调用，以及探测耗尽与发送后的退出路径。

9 组机器码检查通过；原文件通过、10 个单字节篡改分别被拒绝，共 11 项夹具通过。最终验包重新检查实际字节，并绑定应用、安装器、源码和 run 的哈希。报告与反汇编保存在产物目录 `verification/windows-native-code-review.md`、`windows-single-instance-disassembly.txt` 和 `windows-native-code-check.json`。该静态审查确认程序包含相应策略，Windows GUI 双开与 IPC 实测仍待设备验收。应用包无需为日志判据重建。
