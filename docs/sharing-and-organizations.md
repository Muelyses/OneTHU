# 暂存箱、口令、名片与组织

中文 · [English](en/sharing-and-organizations.md)

## 暂存箱的使用

暂存箱是完整模式的本机收纳层。短按按钮打开管理，长按按钮可换位置；拖动内容和拖动按钮是不同手势。接收扫描仅在内容长按拖动期间强调目标，普通点击不展开大型雷达。

自动演示使用虚构作业，经过实际长按、拖动、命中目标和收纳代码，并在打开暂存箱后核对同一标题。圆形标记只表示指针位置。

![模拟长按拖入暂存箱](assets/0.11/vault-drag.gif){ width="300" }

1. 在支持的条目上长按，等待内容提起。
2. 保持按住，移向暂存箱按钮周围的高亮接收区。
3. 松手完成收纳；打开暂存箱查看结果。移到 OH 接收区则进入另一条发送给 OH 的路径。

## 当前支持的拖动来源

| 来源 | 具体内容 |
|---|---|
| 白板 | 已接入的组件与卡片 |
| 标签与 OneGO! | 页面标签、工作区、收藏入口 |
| 搜索与收藏 | 功能结果、已注册对象、收藏项 |
| 网络学堂 | 作业、通知、文件条目与已接入的附件 |
| 日程 | 已接入的课程、作业截止、自定义日程条目 |
| 通讯录 | 个人名片与组织名片 |
| 文件与协作 | 云盘文件/目录、邮件、GitLab 项目、新闻及附件 |
| 个性化与扩展 | 已接入的主题、壁纸、插件条目与设置行 |

支持来源来自 `data-vault-catch`、`vaultCatch*` 构造器及旧 `data-ctx-atom` 适配，不能推断任意网页文字、任意表单控件都能拖动。桌面选中文字另有 `Ctrl/⌘+Shift+S` 收纳入口。远端文件可能需要缓存；条目引用不等于复制了远端全部内容。

## 短口令与接收

短口令通过网络取回分享清单。发送端需完成相应云盘接入；文件是否已上传、分享是否公开或限定接收账号，均影响接收结果。短口令不是对任意长串直接做 Base64 压缩，也不承诺离线传输大文件。界面使用统一分享入口，避免同一内容在多个位置产生互相矛盾的口令。

**NFC 目前可用性不稳定，请尽量使用口令。** NFC 受设备、系统、原生构建与权限影响；演示不能证明实体硬件接力成功。极简、实用模式不接收完整模式的名片、组织与暂存内容。

## 好友与组织

通讯录是完整模式一级功能，管理个人名片、好友和组织。组织创建后绑定组织名片，名片不是独立的组织身份。组织界面提供成员、文件、项目与公告管理；本地保存的组织索引不能作为服务端授权。

多人协作涉及 GitLab 与清华云盘的不同资源。成员角色、文件权限、项目权限需分别向服务端验证；对方尚未接收邀请、账号未接入或学校服务未返回最新状态时，界面可能仍显示待处理。好友通道刷新与邀请通知不保证学校服务实时推送。

## 多设备同步与冲突

同一云盘账号下的私有 `OneTHU-Profile` 保存名片、好友索引与组织索引。每台设备写独立记录；独立字段与条目默认自动合并，删除使用墓碑。真正的同字段互斥修改或删除/修改矛盾显示卡片对比，必须在两个版本中选择；其他可合并字段继续保留。

登录凭据、API Key、服务端权限缓存不随名片索引同步。旧设备从未上传的本机资料，需要先在该设备更新并同步。OH 记忆库 `OH-Memory` 与个人资料库不是同一用途。

实现与验收边界见 [个人资料同步记录](plans/2026-10-21-profile-cloud-sync.md)、[组织协作记录](plans/2026-10-20-organization-collaboration.md)。真实双账号组织联调入口保留，浏览器夹具通过不能代替实体 Win/Mac 或双校园账号验收。
