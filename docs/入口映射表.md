# 入口映射表（0.11）

中文 · [English](en/入口映射表.md)

| 入口 | 极简 / 实用 | 完整 |
|---|---|---|
| OH 胶囊 | 搜索、自填 API、微信/飞书入口 | 搜索、OH 与已授权工具 |
| OneShot | 学习、预约、生活、信息、课表 | 同样五项，可按设置调整 |
| 首页 | 今日待办、近期课程；实用提供更多服务 | 可移动、缩放和删除组件的白板 |
| 顶栏 | 当前上下文与相关设置 | 标签页、我的；OneGO 在胶囊下方收藏栏 |
| 我的 | 仅保留当前模式相关设置 | 名片、外观布局、数据同步、插件与 OH 等设置 |
| 共享 | 不接收隐藏的高级共享能力 | 暂存箱、口令、NFC、名片与组织 |

当前页面路由与可用入口以 `apps/desktop/src/state`、`components/explorer`、`lib/onboardingNavigation.ts` 及实际模式策略为准。旧「今日/待办/服务/收藏/我的」五标签方案属于历史设计，不能据此新增一套导航。
