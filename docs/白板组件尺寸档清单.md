# 白板组件尺寸档清单（逐个设计排版用）

> 生成于 2026-10-11，口径由霖在本次会话确认（见 §0）。
> 机读事实源：`apps/desktop/src/state/widgets.ts` 的 `SIZE_PLANS` 与 `freeSizeWidgetIds()`。
> 本清单只列**需要分别设计不同大小排版**的组件；其余组件保留自由控制，不参与逐档设计。

---

## 0. 本次确认的口径

1. 取消所有组件的自由缩放。只有四类特殊组件保留自由控制：**分割线、标题（文字）、入口按钮、列表**。
2. 其余组件改为**挡位控制**：每个档位一套专门排版，尺寸只能从该组件的档位清单里挑。
3. 档位沿用本仓库基准网格：1 单位 = 手机 1 列。提案用到 1×1 / 2×1 / 2×2 / 4×1 / 4×2 / 4×4。
4. 「添加组件」抽屉的展开态改为**横向滑动的档位列表**：滑到哪一档，底部「添加」就加哪一档。
5. 长按菜单「改变大小」**复用同一个抽屉**：自动选中当前档位，底部按钮为「修改大小」，
   确认后替换该位置组件的尺寸，四周组件按既有重排算法让位。
6. 挡位组件**不参与按内容撑高的拟合**：档位是唯一尺寸。
7. 历史文档不做一次性迁移；尺寸在**渲染**与**写入**两处按最近档位吸附。

## 3. 逐档排版的落地方式

两种钩子都已在本次改动里接好，设计排版的下一步只需写其中一种。

### 3.1 只改样式：槽位的 `data-widget` 与 `data-size`

每个槽位带 `data-widget="custom:<id>"` 与 `data-size="<w>x<h>"`。示例：

```css
.board-slot[data-widget="custom:mine-gpa"][data-size="1x1"] .mine-stat-label { display: none; }
.board-slot[data-widget="custom:mine-gpa"][data-size="2x2"] .mine-stat-num { font-size: 28px; }
```

### 3.2 需要换结构：渲染器的第二个参数

卡体渲染器签名是 `(props?, size?) => ReactNode`，`size` 即当前档位。示例：

```tsx
[cardRendererKey("mine-gpa")]: (_props, size) => <MineGpaCard size={size} />,
```

抽屉里的档位预览走同一套渲染器与同一个 `data-size`，因此设计出的排版在预览与白板上一致。
